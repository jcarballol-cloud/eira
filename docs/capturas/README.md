**Versión en castelán:** [máis abaixo](#capturas-de-pantalla-es).

Para que o repositorio se poida clonar rápido, aquí só quedan **11 capturas clave** (6 da demo da
v1.4 e 5 da v1.5, con datos ficticios). O resto das capturas de cada pantalla (todas as versións, en

- As ligazóns a capturas que hai noutros documentos (`docs/capturas/v1.1/`, `v2/`, `v3/`, `v4/`,
  `v5/`…) refírense a esa colección completa.
